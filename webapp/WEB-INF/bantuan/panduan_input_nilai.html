Panduan Input Nilai (Dosen)

Mengisi nilai perkuliahan — dari format nilai sampai mengunci, termasuk cara menelusuri nilai akhir yang tetap 0.

Alur singkat: Atur Format Nilai → Isi nilai komponen → Hitung Ulang → Verifikasi → Kunci.

1. Menyiapkan format nilai

Klik Ubah Format, pastikan seluruh komponen terdaftar, lalu isi bobot persen tiap komponen (umumnya total 100%). Selesaikan ini sebelum mulai mengisi nilai.

Bobot persen tidak boleh kosong
Bila seluruh bobot bernilai 0 atau kosong, sistem tidak punya pembagi untuk menghitung — nilai akhir akan selalu 0 berapa kali pun Anda menekan Hitung Ulang.

2. Mengisi nilai

  1. Isi nilai tiap mahasiswa pada kolom komponen. Nilai tersimpan otomatis saat berpindah kolom.
  2. Gunakan kotak Mhs lalu Cari untuk melompat ke mahasiswa tertentu.
  3. Setelah selesai, klik Hitung Ulang agar nilai akhir dan nilai huruf diperbarui.
  4. Periksa kolom Total — pastikan angkanya wajar.

Untuk kelas besar tersedia Download (unduh berkas kerja) dan Upload (unggah kembali setelah diisi), serta Masukkan Nilai Absen dan Ambil Nilai dari Feeder. Setelah mengunggah, tetap klik Hitung Ulang.

3. Nilai akhir tetap 0 — lima kemungkinan sebab

Bila kolom Total menunjukkan 0 padahal komponen sudah terisi, sistem menampilkan peringatan merah pada baris mahasiswa tersebut. Berikut kelima sebab dan tindakannya:

Urutan pemeriksaan yang disarankan
Periksa berurutan: (1) apakah nilai sedang terkunci — ini penyebab tersering; (2) apakah bobot persen sudah terisi; (3) tekan Hitung Ulang. Bila ketiganya benar dan tetap 0, periksa presensi dan aturan nilai 0.

4. Verifikasi dan mengunci

Verifikasi menandai nilai sudah Anda sahkan. Bila kampus mengaktifkan "Sembunyikan nilai ke mahasiswa jika belum diverifikasi", mahasiswa belum dapat melihat nilainya sampai Anda memverifikasi. Kunci membuat seluruh kolom nilai hanya-baca; Buka mengembalikannya bila masih perlu perbaikan.

Kunci hanya setelah semua nilai benar
Mengunci ketika masih ada komponen kosong menimbulkan persoalan pada Sebab 1 di atas — nilai akhir membeku di 0 walau kemudian Anda mengisi angkanya.

Biasakan menutup pekerjaan dengan urutan: Hitung Ulang → periksa Total → Verifikasi → Kunci.
