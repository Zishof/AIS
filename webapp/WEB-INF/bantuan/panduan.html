Pusat Panduan Pengguna

Kumpulan panduan singkat untuk pengguna e-campus. Pilih panduan yang sesuai dengan peran Anda. Halaman ini dapat dibuka dari mana saja melalui alamat bantuan?key=panduan.

PanduanIsi ringkas
Panduan Petugas PerpustakaanKunjungan barcode, repository, dan penerbitan katalog
Panduan Unggah Karya Ilmiah (Mahasiswa)Melengkapi judul, abstrak, dan berkas skripsi
Panduan Admin PPDBGelombang pendaftaran dan form tambahan
Panduan Pendaftaran PPDB (Calon Siswa)Langkah mendaftar untuk calon siswa dan orang tua
Panduan Input Nilai (Dosen)Mengisi nilai dan menelusuri nilai akhir 0
Panduan Pengisian KRS (Mahasiswa)Mengisi KRS sampai disetujui dosen PA
Panduan Persetujuan KRS (Dosen PA)Memeriksa dan menyetujui KRS mahasiswa bimbingan
Panduan tidak menggantikan ketentuan resmi
Nama menu dan sebagian aturan diatur masing-masing kampus/sekolah, sehingga tampilan Anda dapat berbeda. Untuk ketentuan resmi, ikuti pengumuman institusi Anda.
