Tentang halaman ini

Halaman ini digunakan untuk mengelola template query, yaitu pengelolaan template query, yaitu kumpulan perintah pengambilan data yang disimpan agar dapat dipakai ulang untuk kebutuhan pelaporan atau pengolahan data, mencakup nama, query, dan keterangan. Pengelolaan yang tertib menjadikan tiap template query terdokumentasi dengan jelas, sehingga pengambilan data untuk laporan dapat dilakukan cepat melalui template. Berbeda dari laporan yang menyajikan hasil maupun data sumbernya, halaman ini menata template query secara tersendiri. Melalui halaman ini, tiap template query dapat dicatat, ditinjau, diubah, dan ditelusuri beserta unsur-unsurnya. Pengelolaan mencakup pencatatan, penetapan nama template, isi query, parameter, serta keterangan, pembaruan, hingga pemanfaatannya sebagai dasar penyusunan laporan dan pengolahan data. Panduan ini disusun berurutan agar Anda memahami fungsi tiap bagian serta langkah yang perlu disiapkan, dilakukan, dan diselesaikan dari awal hingga akhir dengan tertib.
